# Z-zero

종아리 부하를 미리 감지해서 쥐를 막고, 다이얼 카메라로 발 움직임을 분석하는 **스마트 카프 슬리브 앱**이에요.
웹앱(PWA)이라서 링크로 열고, 폰 홈 화면에 앱처럼 설치할 수 있어요.

> 지금은 **데모 모드**예요. 실제 슬리브 대신 시뮬레이터가 센서 값을 만들고, 기록은 각자 폰(브라우저)에만 저장돼요.

## 앱 열기 · 설치

- 링크: `https://efn371d.github.io/Z-zero/`
- **아이폰**: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- 컴퓨터로 열면 폰 모양 화면으로 보여요
- 발표·시연 때는 주소 끝에 `?demo`를 붙이면 (`https://efn371d.github.io/Z-zero/?demo`) 왼쪽에 **화면 바로가기** 목록이 나와요. 보통 링크에는 안 보여요.

## 앱 흐름

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 시작하기 | 시작 → 연결 → 착용 체크 | 다이얼 돌려 시작, 양쪽 슬리브 연결, 영점 + 10초 기준 측정 |
| 운동 | 오늘 → 운동 선택 → 운동 설정 → 카메라 안내 → 촬영 중 → 운동 중 → 종아리 경고 | 부하가 경고 기준을 넘으면 진동 + 경고 화면, 다이얼 ½바퀴 조이면 부하 −18 |
| 리뷰 | 분석 → 분석 상세 → AI 인사이트 → 기록 → 설정 | 점수, 10분별 부하, 그래프, 클립, 회복 루틴 타이머, 달력 |

## 데모 시뮬레이터가 계산하는 방식 (`js/sim.js`)

1초마다:
- **부하 증가** = 0.017 × 종목계수 × 운동강도 × 그날 컨디션 × 좌우계수 × 다이얼계수 × (1 + 경과시간/1시간) × 랜덤(0.6~1.4)
  - 좌우계수: 약한 다리 1.15~1.35배, 반대쪽 0.72배 → 풋살 경기 기준 약한 다리가 30분 안팎에 60%에 도달
- **경고**: 왼/오 중 큰 값 ≥ 경고 기준 + 민감도 보정(낮음 +5 / 보통 0 / 높음 −5)
- **다이얼 ½바퀴**: 그쪽 부하 −18, 이후 오르는 속도 ×0.6, 압박 +5 mmHg (압박 상한까지만)
- **쥐**: 부하 88% 도달 시 발생 (쥐 +1, 부하 70으로)
- **점수** (`js/data.js`): 100 − (최고 부하 − 40)×0.6 − 쥐×12 − 경고 횟수×1 → 75점 이상 안정, 55점 이상 주의, 그 아래 위험

데모 시간 배속은 **설정 → 데모 시간 배속**에서 바꿀 수 있어요 (기본 10×: 1분에 10분 진행).

## 파일 구조

```
index.html              앱 첫 페이지
manifest.webmanifest    홈 화면 설치 정보 (이름, 아이콘, 색)
sw.js                   오프라인 지원
css/app.css             공용 스타일 (폰 프레임, 시트, 토스트)
js/app.js               화면 전환, 버튼 처리, 시뮬레이터 구동
js/store.js             상태 저장 (기본 설정값은 여기 DEFAULTS)
js/sim.js               센서 시뮬레이터 (부하·경고·다이얼 계산)
js/data.js              종목 목록, 분석 계산(점수·회복 플랜), 데모 기록 생성
js/ui.js                공용 조각 (상태바, 하단 탭, 다리 아이콘, 슬리브 그림)
js/lang-en.js           영어 번역 (한국어 → 영어)
js/screens/*.js         화면 15개 — 화면 하나 = 파일 하나
assets/img              사진 (Higgsfield 렌더에서 잘라 씀)
assets/video            3초 영상 (촬영 화면, 카메라 안내, 클립, 시작 화면 배경)
assets/fonts            Wanted Sans(본문) · Teko(브랜드 글자·큰 숫자)
assets/icons            앱 아이콘 (Z 로고)
```

## 자주 하는 수정

- **글자 바꾸기**: `js/screens/화면.js`에서 `${t("바꿀 문구")}`를 찾아 고치고, 영어도 필요하면 `js/lang-en.js`에 `"한국어": "English"` 추가
- **기본 경고 기준 등 기본값**: `js/store.js`의 `DEFAULTS`
- **종목 추가**: `js/data.js`의 `SPORTS` 목록 (+ `js/sim.js`의 `FACTOR`에 계수)
- **회복 루틴 단계**: `js/data.js`의 `analyze()` 안 `plan`
- **사진·영상 교체**: `assets/img/`, `assets/video/`에 같은 이름으로 덮어쓰기 (영상은 .mp4 + 같은 이름 .jpg 썸네일)
- **로고**: `js/ui.js`의 `logoSvg()` (도형 좌표), 브랜드 글자는 `DISPLAY` 서체
- 수정 후 폰에 바로 반영이 안 되면 `sw.js`의 `VERSION` 숫자를 올리기 (예: `z-zero-v2`)

## 컴퓨터에서 실행해 보기

파일을 더블클릭하면 안 열리고, 간단한 서버가 필요해요:

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

데모를 처음부터 다시 보려면 **설정 → 데모 데이터 초기화** (또는 `?demo` 화면 왼쪽 **데모 처음부터**).
